# `doc-platform-core`

> **Scope:** `doc` | **Component:** `platform` | **Status:** Active
> **Org:** [`by-openclaw/doc-platform-core`](https://github.com/by-openclaw/doc-platform-core) | **License:** CC BY-SA 4.0

Central documentation repository for the BY-SYSTEMS platform. Holds **architecture decisions, operational rules, and platform-wide documentation** — no code.

All platform-wide decisions are in **scoped ADRs** under [`docs/adr/`](docs/adr/) organized by concern (identity, git, naming, security, infra, services, lib). Operational rules that apply to every repo live in [`OPERATING-STANDARD.md`](OPERATING-STANDARD.md).

## Key files — always read first

Before creating or editing any file in this repo, agents read in this order:

1. [`OPERATING-STANDARD.md`](OPERATING-STANDARD.md) — mandatory platform rules
2. [`CLAUDE.md`](CLAUDE.md) — repo-specific context
3. [`docs/adr/naming/0001-infra.md`](docs/adr/naming/0001-infra.md) — mandatory before creating any infrastructure-related file
4. [`docs/adr/naming/0004-automation.md`](docs/adr/naming/0004-automation.md) — mandatory before creating any repo, Python, Ansible, or Terraform artifact

## Conventions

- All docs: Markdown, English only
- Diagrams: PlantUML source in `assets/diagrams/`, rendered via Kroki (see `docs/adr/infra/0001-platform-stack §4 Documentation`)
- Binary assets: Git LFS (`.gitattributes`)
- Commits: [Conventional Commits](https://www.conventionalcommits.org/) (`docs`, `chore`, `fix` only for this repo — see `CONTRIBUTING.md`)
- Versioning: Release Please (automatic semver bumps, never edit version strings manually)
